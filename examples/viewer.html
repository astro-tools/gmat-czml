Open this over a local web server

This page is loaded from a file:// URL. Browsers treat that as a unique origin and block the cross-origin Web Workers CesiumJS needs, so the 3D globe can't load.

From the repository, run

python examples/serve.py

and it will serve this folder and open the viewer for you.
